# Polyant v1.0.0

Polyant v1.0.0 is the first public open-source release of a platform for building and operating configurable AI assistants. It brings together a multi-agent runtime, durable context, multi-channel delivery, and an administrative surface for running assistants in an organization.

## Highlights

- **Multi-agent runtime.** A Supervisor coordinates tools and can delegate focused work to isolated sub-agents. Agent-to-agent handoffs are bounded, preventing unbounded delegation chains.
- **Durable context.** Automatic long-term memory combines pgvector similarity search and PostgreSQL full-text search, with configurable embeddings and deduplication.
- **Multiple delivery channels.** Connect assistants to Telegram, Slack, WhatsApp, webhooks, or the OpenAI-compatible HTTP API.
- **Provider flexibility and secure extensibility.** Route requests through OpenAI, Anthropic, Amazon Bedrock, or Nebius; store per-instance secrets encrypted; and extend behavior with tools, plugins, hooks, and Markdown skills.
- **Operational administration.** Manage multiple instances, audit activity, inspect conversations, monitor analytics, and apply the included migrations and security controls from the admin surface.

## Getting started

Start with the [Quickstart](https://docs.polyant.ai/getting-started/quickstart).

## Upgrading a development installation

1. Back up PostgreSQL.
2. Run `npm ci`.
3. Run `npm run db:migrate`.
4. Run `npm run build`.
5. Restart the services, then smoke-test sign-in and a representative chat.

## Compatibility

Semantic Versioning applies to the documented OpenAI-compatible API, Plugin SDK and manifest, and documented configuration and migration behavior. Internal engine modules and the admin UI are not public SemVer surfaces.
