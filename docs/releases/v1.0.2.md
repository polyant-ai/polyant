# Polyant v1.0.2

Polyant v1.0.2 is a patch release. It adds an explicit "Disabled" option to the
per-agent Speech-to-Text provider setting.

## Highlights

- **Explicit "Disabled" STT provider.** The Speech-to-Text provider selector in the
  admin panel now offers a fourth option, "Disabled", alongside OpenAI Whisper, Amazon
  Transcribe, and Deepgram. Previously an unset or unrecognised provider value fell
  back silently to OpenAI Whisper, which could send a voice message to a provider the
  operator never configured. An agent set to "Disabled" now replies "Voice messages
  are not supported. Please type your message instead." to any incoming audio.

## Upgrading

No database migration and no new configuration variable. An agent's STT provider
setting is unchanged unless an operator explicitly selects "Disabled" in the admin
panel.

1. Back up PostgreSQL.
2. Run `npm ci`.
3. Run `npm run build`.
4. Restart the services, then smoke-test a voice message on a channel with STT
   configured.

## Compatibility

Semantic Versioning applies to the documented OpenAI-compatible API, Plugin SDK and
manifest, and documented configuration and migration behavior. Internal engine
modules and the admin UI are not public SemVer surfaces.

This release adds one accepted value (`"disabled"`) to the `sttProvider` field on the
agent management endpoints; it removes and changes no existing value.
