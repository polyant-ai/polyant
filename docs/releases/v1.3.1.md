# Polyant v1.3.1

Polyant v1.3.1 is a patch release for the admin panel. Lists and tab bars now
look and behave the same on every page, the analytics trend badges report the
right direction, and charts move to Recharts 3.

## Highlights

- **One shape for lists.** The same spacing and columns everywhere; the whole
  row opens the item, and controls in a row never do.
- **Chip tab bars** on every page that has tabs.
- **Honest trends.** The analytics cards show the real direction of a change,
  and show nothing when the previous period had no data instead of "+100%".
- **Recharts 3** for the charts.

## Breaking changes

None for operators. For API clients: the `overview.trends` values returned by
`GET /api/analytics` are `null` when the previous period is zero, where they
used to be `100` (or `0` when both periods were zero).

## Security

None.

## Upgrading

No database migration and no new configuration variable.

1. Run `npm ci`.
2. Run `npm run build`.
3. Restart the services.
