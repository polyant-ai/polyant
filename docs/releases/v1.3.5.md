# Polyant v1.3.5

Polyant v1.3.5 adds OpenAI's GPT-6.1 models and a fast mode, lets each agent
decide what happens to the text a model writes alongside a tool call, and
reworks the analytics dashboard. It stops WhatsApp and Telegram from cancelling
a turn that has already run a tool, which could run it a second time, and moves
the engine to Zod 4.6.6 for a security fix. Its two migrations run on their own
at start-up.

## Highlights

- **GPT-6.1.** `gpt-6.1-terra` ($1 / $5 per million tokens, reasoning can be
  switched off) and `gpt-6.1-sol` ($2 / $10, always reasons). The OpenAI
  `standard` tier now resolves to `gpt-6.1-terra`.
- **Fast mode.** Claude Opus 5.5 and OpenAI GPT-5.6, GPT-6 and GPT-6.1 appear a
  second time in the model select and catalog as "· Fast". The provider bills
  those calls at 2× every rate, and the engine prices a call fast only when the
  provider reports that it ran fast.
- **Text written alongside tools.** A model often writes a greeting or even the
  answer in the same step as a tool call. That text used to be dropped on
  WhatsApp and HTTP and shown on a live chat. An agent can now discard it, show
  it as progress, or make it part of the reply, and the prompt tells the model
  which. Unset keeps the previous behaviour.
- **Analytics dashboard.** Every KPI compares with the previous period and
  draws its daily shape; the cost chart overlays the previous period; tools are
  one table with calls, success rate and p95; a weekday × hour heatmap shows
  when people write. The page no longer scrolls sideways on a phone.
- **WhatsApp and Telegram.** A message fragment that arrives once the turn has
  started a tool waits for that turn to finish and gets a turn of its own,
  and a tool the first turn ran is not run again.
- **Webhook turns and rooms** run with the agent's fast mode, reasoning level
  and temperature.

## Breaking changes

- Agents on OpenAI with no model of their own, and their `spawnTask`
  sub-agents, move from `gpt-6-sol` to `gpt-6.1-terra`. The OpenAI key must
  have access to it.
- `hourlyDistribution` in the analytics responses has 168 rows with a
  `weekday` field instead of 24. A client that reads it outside the panel must
  follow.
- The message of a validation `400` follows Zod 4's wording. The status codes
  are unchanged.

## Security

- Zod 4.6.6 fixes GHSA-mrhx-c7xc-m3w5, where an array schema without a length
  bound could exhaust memory on a large request. Plugins keep working:
  `@polyant-ai/plugin-sdk` 1.12.0 accepts plugins written with Zod 3 or 4.

## Upgrading

No new configuration variable. Migration `0097` adds `instances.fast_mode`
(`false` for every agent) and migration `0098` adds
`instances.intermediate_text` (empty, the previous behaviour).

1. Run `npm ci`.
2. Run `npm run build`.
3. Restart the services.
