# Polyant v1.1.2

Polyant v1.1.2 is a security patch release. It contains library updates for
security reasons, including Next.js 16.3.6 in the admin panel. Anyone running
1.1.1 or earlier should upgrade.

## Breaking changes

None.

## Security

Library updates for security reasons. Application behaviour is unchanged.

## Upgrading

No database migration and no new configuration variable.

1. Run `npm ci`.
2. Run `npm run build`.
3. Restart the services.
